# 건호 · 주훈

서버 하나에서 일기와 음악을 관리하는 Discord 스타일 아카이브입니다.

## 구성과 기능

디스코드와 같은 4단 화면: 서버 목록 · 채널 목록 · 대화 · 멤버 목록

- **텍스트 채널** 일기 / 음악, **음성 채널** 라운지(연출), **공개** 방명록
- **답장**: 메시지 위 도구 모음의 화살표 → 원본이 위에 작게 붙고, 누르면 원본으로 이동
- **반응**: 이모지로 반응, 다시 누르면 취소. 누가 눌렀는지 마우스를 올리면 보여요
- **고정 메시지**: 핀 버튼으로 고정 → 상단 핀 아이콘에서 모아 보기
- **검색**: 상단 검색창(Ctrl/⌘+K) — 불러온 메시지 안에서 찾아요
- **멤버 목록**: 오른쪽 패널, 이름을 누르면 프로필 카드
- **채널 환영 화면**, 날짜 구분선, 7분 안 연속 메시지 묶음, (수정됨) 표시
- 단축키: Enter 전송 · Shift+Enter 줄바꿈 · ↑ 내 마지막 메시지 수정 · Esc 답장/수정 취소
- 사진 첨부·확대, 유튜브 미리보기·재생, 마크다운(굵게·기울임·밑줄·취소선·인용·목록·코드·스포일러·링크)
- 휴대폰: 왼쪽 위 메뉴로 채널, 멤버 아이콘으로 멤버 목록, 메시지를 누르면 도구 모음
- 로그인 없이 열려 있어요. 주소를 아는 사람은 누구나 일기 작성·수정·삭제가 가능합니다.

## 고치고 싶을 때

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 서버 이름, 멤버 이름·색·역할, 채널 이름·설명·환영 문구, 이모지 목록 | `public/config.js` |
| 색·크기·간격 | `public/style.css` 맨 위 `:root` |
| 화면 동작 | `public/app.js` (맨 위 목차 참고) |
| 서버 API | `api/index.js` (맨 위 목록 참고) |

채널을 새로 추가할 때는 `public/config.js`의 `channels`와 `api/index.js`의 `CHANNEL_KINDS`에 같은 키를 넣고, `schema.sql`의 `kind` 허용 목록에도 추가하세요.

## 업데이트 (답장·반응·고정을 처음 쓸 때 한 번)

Supabase → SQL Editor에서 `schema.sql` 맨 아래 **"업데이트: 답장 · 반응 · 고정 · 수정 표시"** 부분을 실행하세요. 기존 기록은 그대로 남습니다. 실행 전에는 글쓰기·수정은 되지만 답장·반응·고정을 누르면 "데이터베이스 업데이트가 필요해요"라고 나옵니다.

## 샘플 실행

Node.js 22 이상이 설치된 컴퓨터에서 이 폴더를 열고:

```sh
npm run dev
```

`http://localhost:3000/?demo=1`에 접속하세요.
샘플에서는 왼쪽 아래 로그인 아이콘으로 작성자 / 방문자 흐름을 전환할 수 있습니다. 프로필 사진과 메시지는 이 브라우저에만 저장됩니다. 샘플 내용은 해당 브라우저에만 저장됩니다. 기존 버전의 샘플 기록이 있으면 일기·노래로 가져옵니다. 실제 공유 방으로 이전되지는 않습니다.

## 실제 공유 방 연결

아직 Vercel 배포와 Supabase 연결은 완료되지 않았습니다. 공유 저장소 연결 전에는 샘플임을 표시하며 로컬 모드로 동작합니다. 두 사람이 함께 사용하거나 실제 방문자의 방명록을 받으려면 다음 설정이 필요합니다.

1. https://supabase.com 에서 프로젝트를 만드세요.
2. SQL Editor에서 `schema.sql` 전체를 실행하세요. 기존에 첫 버전을 설정했다면 이 파일을 다시 실행해 방명록·프로필 테이블을 추가하세요. 기존 일기나 노래를 삭제하지 않습니다.
3. https://vercel.com 에서 이 폴더를 프로젝트로 배포하세요.
4. Vercel Settings → Environment Variables에 아래 네 값을 등록하고 재배포하세요.

| 이름 | 값 |
|---|---|
| `SUPABASE_URL` | Supabase 프로젝트 URL |
| `SUPABASE_SERVICE_ROLE_KEY` | 서버용 service_role 키 |
| `ROOM_PASSWORD` | 공유 비밀번호, 12자 이상 |
| `SESSION_SECRET` | 임의의 문자열, 32자 이상 |

비밀 키는 환경변수에 입력하세요. 파일이나 채팅으로 공유하지 마세요. 서버용 키는 anon/publishable 키와 다릅니다.

세션 키 생성 예:

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

GitHub 저장소로 배포한다면 `api/`, `public/`, `package.json`, `vercel.json`이 프로젝트 루트에 있어야 합니다. Framework Preset은 Other, Output Directory는 public입니다.

GitHub 없이 터미널로 배포할 때:

```sh
npx vercel
```

프로젝트를 연결하고 환경변수를 등록한 뒤:

```sh
npx vercel --prod
```

Vercel이 표시하는 실제 `https://프로젝트명.vercel.app` 주소를 사용하세요. 별도의 주소가 자동 생성되었다고 주장하는 파일은 아닙니다.

## 사용 방법

- 첫 방문자는 방명록이 열립니다. 닉네임을 적고 글을 보내면 됩니다.
- 건호와 주훈은 로그인 후 작성자를 골라 일기와 노래를 남깁니다.
- 음악 채널에 유튜브 링크를 붙이면 썸네일이 나타납니다. 재생 제한 영상은 YouTube에서 보기로 여세요.
- 채팅창 상단의 방명록 링크 버튼으로 방문자용 주소를 복사하세요. 주소는 사이트 URL에 `#guestbook`을 붙인 형태입니다.
- 다크 스킨으로 고정되어 있습니다.
- 모바일에서는 왼쪽 서버 아이콘과 상단 채널 메뉴를 사용합니다.

## 저장 및 접근 범위

공유 비밀번호를 아는 두 사람은 전체 비공개 기록을 수정·삭제할 수 있습니다. 선택한 닉네임은 표시 이름이며 개별 계정 인증은 아닙니다.

방명록만 공개되어 누구나 읽고 작성할 수 있습니다. 방문자는 삭제·수정할 수 없으며 일기나 노래의 데이터는 서버에서 차단합니다. 방명록은 IP당 15분 동안 10번까지 작성할 수 있습니다. 로그인 시도 제한은 별도로 적용됩니다. 다른 사이트에서 온 쓰기 요청을 차단합니다.

세션은 7일입니다. 공유 비밀번호를 바꾸고 재배포하면 기존 세션이 무효화됩니다. 화면을 열어 둔 동안 10초 간격으로 새 메시지를 확인합니다.

사진은 한 메시지에 한 장, 원본 12MB 이하입니다. 최대 1200px WebP 정지 이미지로 줄여 데이터베이스에 저장합니다. GIF는 정지 이미지로 저장됩니다. 이 소규모 개인용 버전에서 사진이 많아지면 별도의 파일 저장소로 옮기는 것이 좋습니다.

일기·노래는 8개씩, 방명록은 30개씩 가져옵니다. 이전 메시지로 과거 기록을 불러올 수 있습니다.

## 파일과 확인 범위

- `public/config.js`: 이름·색·채널 설정
- `public/index.html`, `style.css`, `app.js`: 화면과 동작
- `api/index.js`: 인증·일기·노래·공개 방명록 API
- `schema.sql`: 테이블, 서버 전용 접근 권한, 작성 제한
- `vercel.json`: 배포 설정과 보안 헤더
- `dev.mjs`: 로컬 서버

로컬에서 실제 저장소를 연결하려면 `.env` 파일에 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`를 넣고 `node --env-file=.env dev.mjs`를 실행하세요.

헤드리스 Chromium으로 데스크톱·휴대폰 화면에서 채널 전환, 답장, 반응, 고정, 검색, ↑ 수정, 방명록, 음성 연출을 확인했고, 모의 저장소로 API(답장 원본 조회, 반응 토글, 고정 목록, 이전 DB에서의 수정)를 확인했습니다. 실제 Supabase 연결 상태에서는 확인하지 못했습니다.

마크다운 예: `**굵게**`, `*기울임*`, `__밑줄__`, `~~취소선~~`, `||스포일러||`. HTML은 문자로 표시하며 스크립트 링크는 차단합니다. 파서는 MIT 라이선스의 Marked 17.0.5를 포함합니다.

프로필 조회·저장 API의 로그인 권한과 이미지 입력 검증도 모의 데이터베이스로 확인했습니다. 움직임 줄이기 설정이 켜져 있으면 장식 애니메이션을 중지합니다.
